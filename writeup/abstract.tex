Federated learning (FL) trains a shared model without centralising clients' raw data. However, under FL deployment, devices could vary in processor speed, memory budget, and network condition while proprietary data are non-iid. This dissertation studies two systems axes, compute heterogeneity and straggler-induced heterogeneity, while also examining data heterogeneity where relevant. The main conclusion is that accuracy is insufficient for evaluating realistic FL deployment: wall-clock time, staleness, network conditions, parameter coverage, and other system effects are important to consider.

This dissertation develops \textbf{fedctl}, a framework for deploying Flower applications on a Raspberry Pi cluster built from scratch. It supports device-heterogeneous placement, controlled network impairment, and records logs and artefacts through a web interface. This makes it possible to compare FL methods under the same hardware and network conditions, and to compare deployment conditions without changing method code.

Using \textbf{fedctl}, this dissertation first evaluates \textbf{submodel FL} under compute heterogeneity. Submodel FL methods are useful when local compute and memory are constrained on weak devices. \texttt{FIARSE} gives strong deployable submodel quality and global performance, while \texttt{HeteroFL} and \texttt{FedRolex} are faster in wall-clock time. This dissertation then evaluates \textbf{asynchronous FL} under straggler-induced heterogeneity. Asynchronous FL is useful under mixed-device and straggler effects. \texttt{FedAsync} reaches the target accuracy with fewer client trips and lower wall-clock time, at the cost of increased staleness and unstable learning curves. \texttt{FedBuff} mitigates this instability through buffered aggregation. \texttt{FedStaleWeight} improves the underrepresentation of weak devices.

Finally, this dissertation evaluates the combination of asynchronous FL with submodel FL. It first shows that naive composition is feasible under realistic FL deployments, but partial asynchronous updates raise concerns over \textbf{parameter coverage}. To address this, this dissertation proposes \texttt{FedCover}, a coverage-aware aggregation algorithm, and demonstrates improved performance compared to the baseline. Overall, this dissertation shows that comprehensive, realistic FL evaluation requires both system and performance metrics.
